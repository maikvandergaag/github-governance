# Code of Conduct

We want this project to be a respectful, constructive space for everyone, regardless of experience,
identity, background, or point of view.

Expected behavior includes:

- Be considerate, respectful, and open to differing viewpoints.
- Give and accept constructive feedback in good faith.
- Focus discussion on the work and its impact.
- Respect privacy: do not publish secrets, private account data, or personal information.

Unacceptable behavior includes harassment, discrimination, intimidation, personal attacks, and
publishing another person's private information without permission.

Project maintainers may edit or remove contributions and restrict participation when necessary to
protect the community. To report a conduct concern, contact the repository maintainers privately
through GitHub rather than posting sensitive details in a public issue.
